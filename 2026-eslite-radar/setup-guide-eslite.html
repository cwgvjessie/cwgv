誠品工程師設定手冊

專案：職場雷達 × 誠品線上 合作專案  |  負責方：誠品 Eslite  |  文件版本：2026-06-11

你的角色：提供外層頁面框架（shell），把遠見的內容以 <iframe> 嵌入。
你的頁面上不需要安裝任何 GTM 或 GA4 代碼，追蹤代碼全部在遠見那側。
你只需要把 iframe src 的 URL 設定正確，並在 src 後面加一個 query string 參數。

你需要做的事（共 3 個步驟）

步驟 1 — eslite.html：嵌入「職場雷達」列表頁

在你的 eslite.html 中，將 iframe src 設定為遠見提供的 URL，並在結尾加上 ?partner=eslite.com。

<iframe
  id="contentFrame"
  class="content-frame"
  src="https://event.gvm.com.tw/…/gvm-radarlist.html?partner=eslite.com"
  scrolling="no"
  title="職場雷達內容"
></iframe>

同時加入以下 <script>，讓遠見的 iframe 可以自動調整高度：

<script>
window.addEventListener('message', function (e) {
  if (e.data && typeof e.data.iframeHeight === 'number') {
    document.getElementById('contentFrame').style.height = e.data.iframeHeight + 'px';
  }
});
</script>

步驟 2 — eslite-article.html：嵌入「文章內頁」

與步驟 1 相同，只是 src 換成文章內頁的 URL：

<iframe
  id="contentFrame"
  class="content-frame"
  src="https://event.gvm.com.tw/…/gvm-article.html?partner=eslite.com"
  scrolling="no"
  title="職場雷達內容"
></iframe>

同樣加入高度自適應的 <script>（與步驟 1 相同）。

步驟 3 — eslite-aigc.html：AIGC 深度解析頁

這是一個獨立的靜態頁面，由摩速的問題連結以 target="_blank" 開啟。
你只需要確保這個頁面可以正常存取，不需要做任何特別的追蹤設定。

✓ 確認清單
  • eslite.html 的 iframe src 結尾有 ?partner=eslite.com
  • eslite-article.html 的 iframe src 結尾有 ?partner=eslite.com
  • 兩個頁面都有加入 iframeHeight postMessage 監聽器
  • eslite-aigc.html 可正常存取

為什麼需要 ?partner=eslite.com？

遠見的 GTM 追蹤代碼需要記錄「這次流量是從哪個合作夥伴網站來的」，以便在 GA4 報表中區分不同合作方的流量。這個值會作為 partner_site 自訂維度傳送到 GA4。

誰設定放在哪裡值
誠品iframe src query string?partner=eslite.com

iframe 技術規格

屬性值說明
scrollingno由遠見的頁面控制自身捲動
style.height由 postMessage 動態設定需加入監聽器腳本
bordernone / 0視覺整合用
width100%RWD 響應式
⚠️ 注意：請勿在 iframe 標籤上設定 referrerpolicy="no-referrer" 或在頁面 <head> 加入 <meta name="referrer" content="no-referrer">，會影響追蹤功能。
