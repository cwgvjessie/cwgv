## 1. 問題陳述（Problem Statement）

誠品線上以書籍與商品銷售為核心，但站上缺乏「持續更新、能吸引商務／職場族群回訪」的優質內容入口；單純的商品頁難以承接「先被內容吸引、再產生購買」的讀者。透過與遠見雜誌的內容合作，將職場／商業時事文章導入誠品線上，並在文章脈絡中自然嵌入「誠品選書推薦」，可同時解決「內容黏著度不足」與「書籍曝光缺乏情境」兩個問題。

若不做：商務客群停留時間與回訪偏低，選書推薦缺乏觸發情境，內容與電商兩端各自為政。

---

## 2. 目標（Goals）

1. **建立內容入口**：提供每日更新的職場／商業精選文章列表，讓使用者養成回訪習慣（衡量：列表頁 7 日回訪率）。
2. **內容轉導購**：在文章與問答情境中嵌入誠品選書，提升書籍頁導流（衡量：選書區點擊率、由專區帶入的書籍頁 PV 與加入購物車數）。
3. **延長閱讀動線**：以「文章 → 延伸提問 → AI 問答」串接，提高單次到訪的頁面深度（衡量：平均瀏覽頁數、單頁停留時間）。
4. **強化內容差異化**：以 AI 智能問答（含逐字動畫呈現）創造有別於一般新聞頁的閱讀體驗（衡量：問答頁完讀率、CTA 點擊率）。
5. **可被外站嵌入**：問答頁支援以 iframe 嵌入合作站台（如 `health.gvm.com.tw`），擴大內容觸及。

---

## 3. 非目標（Non-Goals）

1. **不做使用者帳號與個人化推薦**：v1 無登入、無依個人偏好排序，內容為人工／統一策展（複雜度高、非核心問題）。
2. **不做站內全文搜尋**：列表頁僅呈現策展清單與近期熱門彈窗，不提供關鍵字搜尋（屬獨立功能，另案評估）。
3. **不做留言、收藏、分享互動**：v1 專注於「讀 → 導購」主動線，社群互動非必要（可列為後續）。
4. **不做問答即時生成**：AI 問答內容為預先產生並存檔的靜態結果，前端僅以動畫「重播」呈現，非即時呼叫模型（避免延遲與成本不確定性）。
5. **不做後台 CMS**：v1 內容以靜態檔／資料陣列維護，不含編輯後台（待量體成長後再評估）。

## 4. 使用者故事（User Stories）

### 讀者（職場／商務內容消費者）
- 作為讀者，我想在一個列表快速看到今天的職場精選文章與分類，以便挑選感興趣的主題閱讀。
- 作為讀者，我想查看近兩週的熱門文章彙整，以便補看錯過的內容。
- 作為讀者，我想在長文先看到摘要、需要時再展開全文，以便快速判斷是否深讀。
- 作為讀者，我在讀完文章後，想針對延伸問題得到一份結構化的 AI 解答，以便加深理解。
- 作為讀者，我想在文章／問答中看到相關的選書推薦，並能一鍵前往購買，以便延伸學習。

### 內容／營運方（誠品 × 遠見）
- 作為營運方，我想將遠見文章導入誠品專區並標示內容來源，以符合合作授權與導流原始文章的需求。
- 作為營運方，我想在每篇文章綁定一組選書推薦，以建立內容到商品的轉換路徑。
- 作為營運方，我想讓 AI 問答頁可嵌入合作站，以擴大內容露出。

### 邊界情境
- 作為讀者，當近期熱門無近兩週資料時，彈窗應顯示「暫無資料」而非空白。
- 作為讀者，當文章長度不足以觸發摘要折疊時，應直接完整顯示、不出現「看更多」。
- 作為讀者，在行動裝置上瀏覽列表時，縮圖可隱藏、版面改為單欄，確保可讀性。

## 5. 功能需求（Requirements）

### 5.1 列表頁（`eslite-radar.html`）

**Must-Have（P0）**
- 頁首導覽列：品牌字樣「Eslite Online」＋「職場雷達」連結。
- Hero 區：欄目標籤「遠見雜誌」、主標「職場雷達」、自動顯示今日日期（前端 `new Date()` 產生）。
- 精選文章清單：每則含分類標籤、標題、摘要、縮圖，整則可點擊進入文章內頁。
- 三大分類視覺區分：高階決策、管理實務、職場成長（各有對應色票與底色）。
- 「近期熱門文章」彈窗：點按後顯示近 14 天的文章彙整，依日期分組，由前端資料陣列依日期區間過濾。
  - 驗收：Given 今日往前推 14 天內有資料，When 點「近期熱門文章」，Then 彈窗依日期由新到舊分組列出，標題列含分類標籤。
  - 驗收：When 點遮罩區／按 ESC／點關閉鈕，Then 彈窗關閉並恢復頁面捲動。
  - 驗收：Given 近 14 天無資料，Then 顯示「暫無資料」。
- 頁尾：版權與「內容合作：遠見雜誌」標示。

**Nice-to-Have（P1）**
- 列表分頁或無限捲動（目前僅 3 則精選，待確認是否需擴充）。
- 分類篩選器（依高階決策／管理實務／職場成長過濾）。

**Future（P2）**
- 由後端 API 動態供稿，取代前端硬編碼的文章資料陣列。

### 5.2 文章內頁（`eslite-article.html`）

**Must-Have（P0）**
- 文章 Hero：分類標籤、封面圖、標題、作者。
- 全文內容：導言（lede）＋段落＋小標（h2）。
- 「看更多」摘要折疊：前端依非空白字元數（門檻約 300 字）量測折疊高度，超過則先收合、加上漸層遮罩與「看更多」按鈕，點擊平滑展開全文後移除按鈕。
  - 驗收：Given 內文超過門檻，Then 預設只顯示摘要並出現「看更多」；When 點擊，Then 展開全文、遮罩與按鈕消失。
  - 驗收：Given 內文未達門檻，Then 完整顯示且無「看更多」。
- 原文連結：導向遠見雜誌原始文章（新分頁）。
- 誠品選書推薦：一組書籍卡片（標題、作者、簡介、價格、行動按鈕），點擊前往對應誠品商品頁（新分頁）；簡介以行數裁切（line-clamp）控制版面，首本可全寬強調。
- 深度思考問題：數則延伸問題，每則點擊導向 AI 問答頁。
- 頁尾同列表頁。

**Nice-to-Have（P1）**
- 選書卡片價格／供貨狀態由商品 API 即時帶入，避免硬編碼過期。
- 閱讀進度指示。

**Future（P2）**
- 文章與選書的關聯由後台設定，而非寫死於頁面。

### 5.3 AI 問答頁（`AIGC.html`）

**Must-Have（P0）**
- 結構化資料：以 schema.org `QAPage` 標記問題與解答，含發佈日期與來源 URL（利於 SEO／引用）。
- 問題標題、解答區（日期、「Answer」標籤、含小標與段落的解答內容）。
- 逐字動畫（打字機效果）：解答以字元級 span 逐一顯示（預設每字約 8ms）；動畫進行中以 typing-mode 暫時內聯排版、避免區塊預先撐開，閒置約 700ms 視為結束後恢復正常排版。
  - 驗收：頁面載入後解答以逐字方式呈現，完成後排版正常、可正常選取與閱讀。
- 程式碼區塊複製鈕：偵測 `<pre>`（含動態新增者）自動加上 Copy 按鈕，支援 Clipboard API 並在不支援時退回 `execCommand` fallback。
- CTA：「回到原始文章」導向文章內頁（新分頁）。
- 誠品選書推薦：與文章內頁一致的選書區。
- iframe 嵌入適配：當頁面被指定合作站（`dev-health.gvm.com.tw` / `health.gvm.com.tw`）以 iframe 嵌入時，調整內容上方間距以避開父站介面。
- 進場動畫（AOS）：非 iframe 情境啟用淡入／縮放動畫。

**Nice-to-Have（P1）**
- 「立即入手 → 立即加入」等文案依情境替換的設定化（目前以前端字串比對替換，較脆弱）。
- 動畫速度／可關閉設定（無障礙考量，尊重 `prefers-reduced-motion`）。

**Future（P2）**
- 由後端即時生成解答（目前為靜態存檔重播）。

### 5.4 共用元件與設計系統（跨三頁）

**Must-Have（P0）**
- 共用字體：Noto Serif TC、Noto Sans TC、EB Garamond（透過 Google Fonts 載入）。
- 共用色彩變數（CSS variables）、導覽列、頁尾、選書區、分類標籤樣式一致。
- 響應式：行動裝置（約 ≤600px）版面調整（列表改單欄、隱藏縮圖、字級縮放等）。

## 6. 導覽動線（Navigation Flow）

```
列表頁（radar）
  └─ 點精選文章 ──▶ 文章內頁（article）
                      ├─ 誠品選書 ──▶ 誠品商品頁（外站）
                      ├─ 原文連結 ──▶ 遠見原始文章（外站）
                      └─ 深度思考問題 ──▶ AI 問答頁（AIGC）
                                            ├─ 誠品選書 ──▶ 誠品商品頁（外站）
                                            └─「回到原始文章」──▶ 文章內頁
```
- 三頁形成「策展清單 → 深度閱讀 → 延伸問答」的閉環，並在文章與問答兩處設置導購觸點。

## 7. 成功指標（Success Metrics）

### 領先指標（上線後數日～數週）
- **列表頁回訪率**：7 日內回訪比例（目標待定，建議設成功門檻＋挑戰值）。
- **文章完讀／「看更多」展開率**：點擊「看更多」之比例。
- **延伸問題點擊率**：由文章內頁進入 AI 問答頁之比例。
- **選書區點擊率（CTR）**：文章／問答頁選書卡片點擊數 ÷ 曝光數。
- **頁面深度**：單次到訪平均瀏覽頁數（目標：跨 ≥2 頁）。

### 落後指標（數週～數月）
- **導購轉換**：由本專區帶入並完成「加入購物車／購買」的書籍數與金額。
- **內容留存貢獻**：使用本專區之使用者整體回訪／停留是否優於對照組。
- **嵌入觸及**：問答頁經合作站 iframe 之曝光與外部導流量。

> 量測方式（工具、事件埋點、時間窗）需與數據團隊確認；目前原型僅見一處 `data-tracked="1"` 標記，埋點規格待補。

## 9. 時程與相依（Timeline Considerations）

- **相依**：
  - 誠品商品頁／商品 API（選書導購與即時價格）。
  - 遠見內容供稿與授權（文章與原文連結）。
  - 合作站（health.gvm.com.tw）之 iframe 嵌入規格。
  - 數據團隊埋點與儀表板。
- **建議分期**：
  - **Phase 1（核心動線）**：三頁靜態版本（現有原型）＋基本埋點，驗證「讀 → 導購」轉換假設。
  - **Phase 2（內容自動化）**：列表／選書改由 API 或 CMS 供稿，價格即時化。
  - **Phase 3（體驗強化）**：分類篩選、無障礙動畫、嵌入觸及擴大、個人化評估。
- **硬期限**：依合作活動檔期而定（待商務確認）。
