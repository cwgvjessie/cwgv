摩速工程師設定手冊

專案：職場雷達 × 誠品線上 合作專案  |  負責方：摩速  |  文件版本：2026-06-11

你的角色：負責兩支頁面（aigc-book.html、aigc-article.html）。
你的頁面不需要安裝任何 GTM 或 GA4 代碼。
追蹤機制由你發送 postMessage 給上層遠見的頁面，由遠見的 GTM 負責記錄到 GA4。
你只需要確保 postMessage 在正確的時機、帶著正確的資料發送出去。

整體架構

Layer 1 — 誠品環境（對方負責）
eslite-aigc.html 無 GTM
iframe src → gvm-aigc.html
↓ iframe embed ↑ iframeHeight postMessage
Layer 2 — 遠見中介頁（對方負責）
gvm-aigc.html GTM 在此
接收 postMessage → dataLayer.push() → GTM → GA4
GTM-5ZH7TSVB GTM
aigc_cta_click book_buy_click aigc_question_click
↓ iframe embed ↑ postMessage(event)
Layer 3 — 摩速 AIGC 頁（你負責）
aigc-article.html 無 GTM
使用者點擊 → window.parent.postMessage() → 遠見接收 → GA4
.cta-button → aigc_cta_click .connect-item → book_buy_click .ask → aigc_question_click
📊 GA4 — Google Analytics
誠品 (最外層) eslite-article.html → <iframe src="遠見 gvm-article.html"> 遠見 (中間層，有 GTM) gvm-article.html → <iframe src="你的 aigc-book.html"> 接收你的 postMessage → GTM dataLayer → GA4 摩速 (你負責，最內層) aigc-book.html → 使用者點擊 → 發 postMessage 給上層遠見 aigc-article.html → 由問題連結開啟（target="_blank"）
postMessage 的傳送方向：你的 iframe 在遠見頁面裡面，所以要用 window.parent.postMessage() 傳給遠見（上一層），而不是 window.top。

檔案一：aigc-book.html（選書推薦 + 深度問題模組）

1-1 「立即入手」點擊追蹤

當使用者點擊購書連結（.connect-item）時，發送 book_buy_click 事件：

document.querySelectorAll('.connect-item').forEach(function (item) {
  item.addEventListener('click', function () {
    var titleEl = item.querySelector('strong');
    window.parent.postMessage({
      event: 'book_buy_click',
      book_title: titleEl ? titleEl.textContent.trim() : '',
      link_url: item.href
    }, '*');
  });
});
postMessage 欄位型別說明範例
eventstring固定值，不可改"book_buy_click"
book_titlestring書名（從 <strong> 取得）"心理安全感的力量"
link_urlstring購書連結完整 URL"https://www.eslite.com/product/..."

1-2 「深度思考問題」點擊追蹤

當使用者點擊問題連結（.article-link）時，發送 aigc_question_click 事件：

document.querySelectorAll('.article-link').forEach(function (link, i) {
  link.addEventListener('click', function () {
    var textEl = link.querySelector('.q-text');
    window.parent.postMessage({
      event: 'aigc_question_click',
      question_index: i + 1,
      question_text: textEl ? textEl.textContent.trim() : '',
      link_url: link.href
    }, '*');
  });
});
postMessage 欄位型別說明範例
eventstring固定值，不可改"aigc_question_click"
question_indexnumber問題順序（從 1 開始）2
question_textstring問題文字（從 .q-text 取得）"哪些競爭優勢在AI普及後..."
link_urlstring連結目標 URL"https://[誠品網域]/eslite-aigc.html"

1-3 問題連結的 href 設定

問題連結的 href 必須指向誠品的 eslite-aigc.html 頁面，並使用 target="_blank" 開新分頁：

<a href="https://[誠品網域]/eslite-aigc.html"
   target="_blank"
   class="article-link">
  <span class="q-text">你的問題文字</span>
</a>
⚠️ 重要：href 填的是誠品的 aigc 頁面網址，不是你自己的 aigc-article.html。
請向誠品確認正式上線後的完整 URL。

1-4 iframe 高度回傳（必須實作）

你的頁面是被嵌入的 iframe，需要主動告知上層遠見頁面目前的內容高度，讓版面自動撐高：

(function () {
  function sendHeight() {
    var h = Math.max(document.body.scrollHeight, document.documentElement.scrollHeight);
    window.parent.postMessage({ iframeHeight: h }, '*');
  }
  var timer;
  function debounced() { clearTimeout(timer); timer = setTimeout(sendHeight, 100); }

  window.addEventListener('load', function () {
    sendHeight();
    setTimeout(sendHeight, 200);
    setTimeout(sendHeight, 600);
    setTimeout(sendHeight, 1200);
  });
  window.addEventListener('resize', debounced);
  new MutationObserver(debounced).observe(document.body, { childList: true, subtree: true });
})();

檔案二：aigc-article.html（AIGC 深度解析頁）

這是一個獨立頁面，由 aigc-book.html 的問題連結以 target="_blank" 方式開啟。
不需要任何追蹤代碼。點擊事件已在開啟前由 aigc-book.html 記錄。
只需確保此頁面可正常存取即可。

HTML 結構規範（aigc-book.html）

遠見的 GTM 會從 postMessage 資料中讀取欄位，因此你的 HTML 元素需對應以下 class 名稱：

功能必要 class / 元素說明
購書連結（立即入手）.connect-item（<a> 標籤）書名取自其內的 <strong>
問題連結.article-link（<a> 標籤）問題文字取自其內的 .q-text
問題文字.q-text（在 .article-link 內）純文字，不含 HTML 標籤

HTML 範例：

<!-- 購書連結 -->
<a class="connect-item" href="https://www.eslite.com/product/...">
  <strong>心理安全感的力量</strong>
  <span>立即入手</span>
</a>

<!-- 問題連結 -->
<a class="article-link"
   href="https://[誠品網域]/eslite-aigc.html"
   target="_blank">
  <span class="q-text">哪些競爭優勢在AI普及後反而會成為包袱？</span>
</a>
✓ 上線前確認清單
  • aigc-book.html 有 book_buy_click postMessage 腳本
  • aigc-book.html 有 aigc_question_click postMessage 腳本
  • aigc-book.html 有 sendHeight postMessage 腳本
  • 問題連結 href 指向誠品的 eslite-aigc.html（已向誠品確認 URL）
  • 購書連結使用 .connect-item class，書名在 <strong> 內
  • 問題連結使用 .article-link class，問題文字在 .q-text 內
  • aigc-article.html 頁面可正常存取
  • 已向遠見確認 postMessage 測試通過

測試方法

你的頁面沒有 GTM，所以無法用 Tag Assistant 直接看到事件。請用以下方式確認 postMessage 有正確發出：

方法一：瀏覽器 Console 監聽

在遠見的測試頁面（gvm-article.html）的 Console 輸入：

window.addEventListener('message', function(e) {
  if (e.data && e.data.event) console.log('postMessage received:', e.data);
});

然後在你的 iframe 裡點擊「立即入手」或「問題連結」，應在 Console 看到對應的物件。

方法二：請遠見工程師用 Tag Assistant 確認

請遠見工程師開啟含有你 iframe 的測試頁面，啟動 Tag Assistant，然後觸發點擊，確認 GTM 有收到 book_buy_click / aigc_question_click 事件。
